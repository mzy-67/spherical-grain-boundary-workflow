# Security policy

This repository contains research software and public example configuration only. Do not commit passwords, access tokens, SSH private keys, private interatomic-potential files, or facility-specific configuration.

Report a suspected credential exposure privately to the repository owner instead of opening a public issue. If a credential is committed, revoke it immediately, rotate any reused credentials, and remove it from the full Git history before publication.

LAMMPS and HPC configuration files are trusted inputs. Only run configurations and model files obtained from sources you trust.
